This is the base every data-source plugin stands on: it comes with each of them, and you never install it yourself. It sets how cx gets data from the sources you install: cx reads each source's own guide first and buys only what the answer needs; it quotes the price first when you ask; and data it paid for but did not receive, it fetches again without paying twice. The raw files it buys are kept in one fixed place in your files, so reading them again costs nothing. Beside each file is a record of the request, holding everything cx wrote in it as written. The dates and figures in them are worked out by code, not guessed. It also handles changes to your data settings, and the plugins you ask cx to install or remove. Each purchase is charged to your balance and listed in Settings › Usage.

## What it costs

Data Source Core itself is free and needs no setup. Each source you install charges for the data cx buys from it, at the price its own page shows.

## How it installs

It installs with each data source that needs it.
