这是所有数据源插件的基础，安装任何一个数据源插件都会一起装上它，你不用单独安装。它规定 cx 怎样从你装的数据源取数据：先读这个数据源自己的说明，只买回答用得到的部分；你想先知道价钱，cx 会先报价；付过钱却没拿到的数据，cx 会取回来，不会再付一次钱。买来的原始文件统一存在你文件里的固定位置，再读不花钱。每个文件旁边都有一份请求记录，cx 在请求里写的内容都原样记在里面。文件里的日期和数字由代码换算，不靠估计。数据设置的修改，以及你让 cx 安装、移除的插件，也都由它来管。每一笔购买都从你的余额扣费，记在「设置」的「用量」里。

## 费用

数据源基础功能本身免费，无需设置。每个数据源按自己页面上的价格，对 cx 从它买的数据收费。

## 安装

它会随每个需要它的数据源一起安装。
